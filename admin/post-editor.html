Publish a Static Post

Posts and images are site files. Edit them in the project, then deploy the updated site.

This page does not save posts. Browser-based pages cannot write files into your project or Vercel deployment. Do not paste data URLs into post content or cover images.

1. Add the image file

Place the original image in assets/images/posts/. Use a short, lowercase filename and keep the image reasonably compressed. The file will be served by Vercel after deployment.

2. Add the post to the static source

Open assets/js/data.js and add a post object inside initialData.posts. Use a unique numeric ID and slug. Keep coverImage as a path relative to the site root.

{
  id: 2,
  title: 'Your article title',
  slug: 'your-article-title',
  category: 'Information Assurance',
  status: 'Draft',
  date: 'Oct 18, 2026',
  readTime: '5 min read',
  author: 'Elyssa',
  featured: false,
  isLatest: false,
  likes: 0,
  views: '0',
  coverImage: 'assets/images/posts/your-cover.webp',
  summary: 'A short description for the post listing.',
  content: `<h2 id="intro">Introduction</h2>
<p>Write the article using HTML elements.</p>`
}

3. Preview and publish

Run the site locally and check the post at blog-detail.html?id=2. Change status to Published when ready. Save the project changes and push them to the connected Vercel repository to publish.

4. Edit or remove a post

Edit or remove its object in assets/js/data.js. Keep an existing ID and slug when editing so current links continue working. Remove an image file only after confirming no post or profile references it.
