# Ely's Blog - Personal Academic Blog (HTML/CSS/JS)

This project contains the complete HTML, CSS, JavaScript, and JSON codebase for **Ely's Blog**, saved directly on your D: drive at `D:\elys-blog`.

---

## 📁 Project Structure

```text
D:\elys-blog/
├── index.html                   # Public Homepage (Hero, Featured & Latest blogs)
├── blogs.html                   # All Blogs page (Search & Category filter pills)
├── blog-detail.html             # Single Article Reader (TOC + Author Bio sidebar)
├── profile.html                 # Profile page (Quick Facts & Connect links)
│
├── admin/                       # 🔒 Admin CMS Dashboard Pages
│   ├── dashboard.html           # Admin Dashboard overview (Metrics & Recent table)
│   ├── posts.html               # Manage Posts Table (All, Published, Draft tabs)
│   ├── post-editor.html         # Create & Edit Blog form
│   ├── categories.html          # Category Manager (+ Add Category modal)
│   └── profile-settings.html    # Profile & Password Settings form
│
├── assets/
│   ├── css/
│   │   ├── style.css            # Public site design system (Cream, Coral, Dark Slate)
│   │   └── admin.css            # Admin Dashboard layout & table styles
│   └── js/
│       ├── data.js              # Blog posts & categories JSON data store
│       ├── main.js              # Public site interactivity & dark mode
│       └── admin.js             # Admin CMS operations
```
